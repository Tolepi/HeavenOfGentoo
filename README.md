Hello everyone! This is a rice im so proud of making, and its really complete with all i need for a cozy, beautiful Gentoo setup. Its heavily inspired on Tokyo Night, and mostly meant for Gentoo Linux systems.

# What do you even have here?
Stuff includes:
- i3 (My window manager)
- Polybar (sexy status bar)
- Rofi (another sexy app launcher)
- Kitty (and probably making an alacritty config soon)
- Btop (task manager for the larpers)
- A firefox theme (and startpage!)
- Cava (which are from Rashidov29s dotfiles, go check them out! making my own config soon tho :3)
- A GTK Theme (which i use for nemo file manager and stuff)
- Neovim (my text editor :3)
And more! (i think? i hope so..)

# But how do i even install it?
Clone the repository, get into it and move all the configurations you want to ~/.config, the theme goes to ~/.themes
```
git clone https://github.com/Tolepi/HeavenOfGentoo
cd HeavenOfGentoo
```
For the firefox theme, you can get it on the Firefox theme store!
https://addons.mozilla.org/en-US/firefox/addon/heaven-of-gentoo/

And for the startpage, place the startpage in ~/.config, go to about:settings#home and in the Homepage section add the following link:
```
file:///home/USER/.config/startpage/index.html
```
(Replace "USER" with your username.)
